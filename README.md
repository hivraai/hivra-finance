# HIVRA Finance

Options research and backtesting with an AI analyst — live at [finance.hivra.ai](https://finance.hivra.ai).

Next.js 15 · Better Auth · MongoDB · Finnhub (quotes) · TradingView (charts) · Databento (options and history).

## Run locally

```bash
npm install
cp .env.example .env.local   # MONGODB_URI, BETTER_AUTH_SECRET, BETTER_AUTH_URL, FINNHUB_API_KEYS
npm run dev
```
